# Установщик зависимостей

Восстанавливает рабочее окружение студии на чистой машине Windows x64.
Запускается одним файлом `install.bat` в корне проекта.

## Что делает

| Шаг | Что устанавливает |
| --- | --- |
| 1 | Проверки: Windows x64, свободное место, интернет, драйвер NVIDIA |
| 2 | Node.js 22 (портативный в `runtime\`) — если в системе нет 18+ |
| 3 | `node_modules` (`npm ci`) + production-сборка `.next` |
| 4 | ComfyUI (**0.44.0** + патчи проекта) + Python **3.12.10** (embedded) |
| 5 | torch **2.11.0+cu130** и 288 пакетов по зафиксированным версиям |
| 6 | 22 кастомные ноды по зафиксированным коммитам + 4 собственные ноды студии |
| 7 | Папки моделей, `extra_model_paths.yaml`, блокировка автообновления |
| 8 | STT-рантайм `transcribe.cpp v0.1.3` в `stt\` (голосовой ввод, CPU, MIT) |
| 9 | Пробный запуск ComfyUI и проверка импорта всех нод |

**Модели не скачиваются.** После установки запустите `start.bat` и скачайте
модели через UI: Настройки → Модели.

## Требования

- Windows 10/11 x64
- 25 ГБ свободного места (само окружение — ~12 ГБ, плюс место под модели)
- Интернет: при установке скачивается ~9 ГБ
- NVIDIA GPU + драйвер CUDA 12.x (без него студия запустится, но генерировать не сможет)

## Запуск

```
install.bat
```

Или с параметрами (PowerShell):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File install\install.ps1 -Force
```

| Параметр | Что делает |
| --- | --- |
| `-Force` | Переустановить всё заново (удаляет `node_modules`, ComfyUI, ноды, кэш) |
| `-SkipApp` | Не трогать Node.js и сборку приложения |
| `-SkipComfy` | Не трогать ComfyUI (Python, пакеты, ноды) |
| `-KeepCache` | Оставить скачанные архивы и pip-кэш |
| `-NoPause` | Не ждать Enter в конце |
| `-Root <путь>` | Другая папка проекта |

Скрипт можно запускать повторно: уже установленные компоненты пропускаются,
поэтому он же работает как «починка» после сбоя.

## Что НЕ восстанавливается

Эта папка не входит в git (слишком большая и проприетарная), установщик про
неё только предупреждает:

| Папка | Размер | Что будет без неё |
| --- | --- | --- |
| `upscale\bin\` | ~1.1 ГБ | вкладка **Upscale** (DLSS 5) не запустится |

Её нужно скопировать с рабочей машины вручную: положить рядом с `start.bat`.
Всё остальное (генерация, продление, refine, FPS, Face Refine, ControlNet,
галерея, голосовой ввод) работает без неё.

**Голосовой ввод** установщик ставит сам: скачивает официальную сборку
`transcribe.cpp v0.1.3` для Windows x64 (MIT, ~10 МБ распакованных, только
CPU-бэкенд) и раскладывает DLL в `stt\`. Модель распознавания (`ggml-*.bin`)
не входит — её скачивают в UI: Настройки → Голос.

## Папка бэкенда (правка 905)

Портативный бэкенд лежит в папке `ComfyUI\` рядом с проектом. Раньше она
называлась `ComfyUI-Easy-Install` (это была сборка Pixaroma) и содержала внутри
ещё одну папку `ComfyUI`; теперь ставим официальное ядро по тегу, и раскладка
плоская:

```
ComfyUI\
├── main.py, nodes.py, server.py ...   ← ядро ComfyUI
├── models\                            ← модели студии (качаются через UI)
├── custom_nodes\                      ← кастомные ноды
├── input\, output\, temp\, user\      ← референсы, готовые видео, кэш, данные ComfyUI
├── extra_model_paths.yaml             ← внешние папки моделей (пишет студия)
├── .no-auto-update                    ← флаг: не даём ядру обновляться самим
└── python_embeded\                    ← портативный Python 3.12 + torch
```

Раскладку установщик определяет сам: если рядом лежит старая
`ComfyUI-Easy-Install\ComfyUI\main.py`, обновление идёт в ней, переименовывать
ничего не обязательно. Если старую папку всё же переименовали в `ComfyUI` и
перенесли содержимое `ComfyUI\ComfyUI\` на уровень выше, повторный запуск
установщика починит `python312._pth` (строка `../ComfyUI` заменяется на `..`).
Менять путь целиком можно и в интерфейсе: Настройки → `comfy_dir`
(он же `config.ini [comfy] comfy_dir`).

## Версия ComfyUI и патчи проекта

Ядро ComfyUI скачивается из тега `v0.44.0` (0.44.0). Если на диске уже стоит
другая версия ядра, установщик обновляет его сам: скачивает новое в кэш,
переносит из старой папки модели, `custom_nodes`, `user`, `output`, `input`,
`temp`, `extra_model_paths.yaml`, а остальное (сам код ComfyUI) заменяет
целиком. При сбое старое ядро возвращается на место.

Поверх ядра установщик при каждом запуске копирует 2 файла из
`install/comfy-patches/`:

| Файл | Зачем |
| --- | --- |
| `comfy_extras/nodes_minimax_h3.py` | наши ноды и правки H3: второй выход `latent` у `MiniMaxH3AddGuide`, `MiniMaxH3AudioOrSilent` / `MiniMaxH3AudioSliceFrom`, flf-фикс keyframe-латентов (правки 146/149), `first_frame` через cover-crop, сохранение пропорций референсов |
| `utils/extra_config.py` | списки путей в `extra_model_paths.yaml` (студия пишет их списками) |

`comfy/ldm/minimax/model.py` и `comfy/model_detection.py` больше не патчим: всё,
что мы в них добавляли (`gate_compress`, `minimax_h3_layout`, `block_index`),
уже есть в 0.44, а наши старые копии удаляли поддержку PDD, FLUX.3, Ming-Image
и ID-V2V.

Копирование идемпотентно: повторный запуск установщика восстанавливает патчи,
даже если ComfyUI уже был установлен или обновлён.

## Если что-то пошло не так

1. Откройте `install.log` в корне проекта — там пошаговый лог с ошибками.
2. Повторите запуск `install.bat`: скрипт продолжит с места сбоя.
3. Если ошибка в конкретной ноде — её можно исключить из `install/nodes.json`
   и запустить установку снова.

Частые причины:

| Ошибка | Решение |
| --- | --- |
| `Недостаточно места` | Освободите диск или перенесите проект на другой |
| `Нет доступа к pypi.org` / `github.com` | Проверьте VPN/прокси, попробуйте снова (проверка идёт через `curl.exe`, ложные срабатывания исключены) |
| `torch не импортируется` | Повторите шаг: `pip` мог скачать битый файл, запустите с `-Force` |
| ComfyUI не поднялся | Смотрите `install.log`: чаще всего не хватает прав или антивирус блокирует `python.exe` |
| Голосовой ввод не работает | Проверьте, что в `stt\` есть `transcribe.dll`; если установка шла без интернета — запустите `install.bat` снова |

## Как обновить версии

Все версии зафиксированы в трёх файлах:

- `install/requirements.lock.txt` — Python-пакеты (288)
- `install/requirements.sdist.txt` — пакеты, собираемые из исходников (8)
- `install/nodes.json` — репозиторий + коммит каждой кастомной ноды
- `install/install.ps1` — версия и SHA256 STT-рантайма (константы `$sttVersion` / `$sttSha`)

Чтобы обновить ноду: поменяйте `sha` на нужный коммит и запустите
`install.bat -Force`.

## Сборка установщика (setup.exe)

Исходник самостоятельного установщика — `install/installer.nsi` (NSIS 3,
Unicode). Он ставит папку приложения без прав администратора в
`%USERPROFILE%\Minimax Studio` (версия в пути не участвует — правки 833, 961) и
на финише одним нажатием запускает установку зависимостей.

Страница выбора папки дописывает `Minimax Studio` к выбранному месту: выбрали
`D:\` — получите `D:\Minimax Studio` (папка создастся сама), выбрали
`D:\Games` — `D:\Games\Minimax Studio` (правка 961). Поэтому у `InstallDir` нет
хвостового `\`, а `NormalizeInstDir` снимает задвоение и не даёт ставить в
корень диска; логика проверяется `node scripts/installer-dir-test.mjs`.

Копию `.nsi` в папку сборки переносите побайтово (`Copy-Item`): без UTF-8 BOM
makensis прочитает кириллицу как ANSI, и в setup.exe будут кракозябры.

Сборка идёт не из корня репозитория, а из отдельной папки рядом с payload:

1. Скопируйте `install/installer.nsi` в папку сборки.
2. Положите рядом папку `src\` — payload установщика: файлы из git +
   `install\cache\` (офлайн-архивы зависимостей) + `upscale\bin\` (runtime
   DLSS). Последние две папки в git не входят из-за размера.
3. Установите NSIS (`winget install --id NSIS.NSIS -e`) и выполните из папки
   сборки: `makensis installer.nsi`.

Результат — `Minimax_H3_Studio_7.1.27_setup.exe`: **~835 МБ** с заполненным
`install\cache\` (офлайн-архивы node, electron, ComfyUI 0.44.0, python-embed, uv,
22 ноды) — установка тогда не качает их из сети; ~450 МБ с пустым кэшем.
Версия файла (Explorer → Свойства → Подробно) задаётся в `installer.nsi`
(`APP_VERSION`), её же видит список «Программы и компоненты». В git exe не
публикуют (лимит GitHub — 100 МБ на файл): он собирается локально и
выкладывается ассетом к релизу.

Два обязательных условия (иначе установка/сборка падает):

- `SetCompressor lzma` **без** `/SOLID`: солидный блок на 1.63 ГБ NSIS 3.13
  не распаковывает — «ошибка записи файла» на ~55-м файле.
- На машине с малым диском `C:` уведите `TMP`/`TEMP` на другой диск, иначе
  `makensis` падает с `Internal compiler error #12345: error creating mmap`.

Подробности — в шапке `install/installer.nsi`.
